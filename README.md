# Trilha de Aprovação

PWA de controle e análise de desempenho em questões de concursos públicos. Funciona 100% offline — todos os dados ficam no IndexedDB/localStorage e podem sincronizar via nuvem.

## Estrutura criada

- Frontend em JavaScript puro
- Shell em HTML com side bar e top bar
- Armazenamento local com `database.js`
- Roteamento simples em `app.js`
- Módulos de dashboard, editais, ciclo, revisões e estatísticas
- PWA com `manifest.json` e `service-worker.js`

## Observação

Este repositório foi montado com a estrutura equivalente do app de referência para servir como base inicial do projeto e permitir evolução incremental.
